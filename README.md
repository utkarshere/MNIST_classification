# Handwritten Digit Classification (MNIST)

This project implements classical machine learning models to classify handwritten digit images (0–9) using the MNIST dataset.

## Models Used

- K-Nearest Neighbors (from scratch)
- Support Vector Machine (with and without PCA transform)
- Decision Tree

## Key Steps

- Data preprocessing and normalization
- Hyperparameter tuning
- Model evaluation using accuracy and confusion matrices
- Misclassification analysis

## Tools

- Python
- NumPy, Pandas
- scikit-learn
- Matplotlib, Seaborn

The notebook contains all experiments, results, and analysis.
